Start with permission-based channels, preserve source attribution, and optimize for verified quality rather than raw signups.

Before paid traffic: complete one registration test and verify that qp_source, qp_campaign, and qp_audience appear in the QuestionPro export. Do not use purchased phone or email lists.

Recommended first 72 hours

  1. MoyaApp: request a data-free research/advertising proposal for broad and lower-income mobile reach.
  2. Existing panel referrals: launch a member-get-member test using a unique referral source ID.
  3. TikTok and Meta: run small controlled creative tests with separate source IDs and equal budgets.
  4. Harambee/SA Youth: pursue an approved partnership specifically for youth representation rather than treating the network as an advertising list.
  5. Daily Maverick: test newsletter/media placement to balance the sample with more urban and highly engaged readers.
  6. SMS: use only first-party, opted-in contacts and include opt-out handling.
